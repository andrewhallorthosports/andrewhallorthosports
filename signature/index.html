Email signature

Dr Andrew J Hall. Hosted on andrewhallorthosports.com. The signature is a set of linked images, so light and dark mode, Mac and iPhone all show it exactly as designed; every line of text is also carried in the image descriptions.

Installing it

  1. Mail on a Mac: open this page in Chrome and press Copy signature. In Mail, open Settings, then Signatures, choose the account and press +. Untick Always match my default message font, delete the placeholder text and paste. The photo may show as a blank box in that window; it appears in new messages.
  2. Mail on an iPhone: the most reliable route is to send yourself an email from the Mac with the new signature, open it on the iPhone, press and hold inside the signature, choose Select All and Copy. Then go to Settings, Apps, Mail, Signature, delete the old text and paste. Straight away, shake the phone and tap Undo on Undo Change Attributes.
  3. Gmail in a browser: Settings, See all settings, General, Signature, Create new, paste, set it as the default for new emails and replies, then Save Changes. The Gmail iPhone app only allows a plain-text signature, so use Apple Mail on the iPhone for this one.
  4. Outlook (Windows, Mac, web): Settings, Mail, Compose and reply, Email signature, then paste. Outlook on Windows does not show background images, so the herringbone falls back to plain Bog and Orkos white; everything else is unchanged.
  5. University account: check whether the University of St Andrews allows a custom signature on that account before replacing the institutional one.

Check before relying on it

  1. Send a test message to a different account and open it on a phone and a computer, in light and dark mode.
  2. Confirm the photo and every link work in that received copy. Some mail clients block remote images until the recipient allows them; the text links still work.
