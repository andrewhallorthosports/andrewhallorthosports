Installing it

  1. Gmail: Settings, See all settings, General, Signature, create or edit a signature, then paste. If the photo does not appear after pasting, use the Insert image button, choose Web address (URL), paste https://www.andrewhallorthosports.com/assets/signature/andrew-hall-photo.jpg and pick the smallest size.
  2. Outlook (Windows, Mac, web): Settings, Mail, Compose and reply, Email signature, then paste.
  3. University account: check whether the University of St Andrews allows a custom signature on that account before replacing the institutional one.

Check before relying on it

  1. Send a test message to a different account and open it on a phone and a computer, in light and dark mode.
  2. Confirm the photo and every link work in that received copy. Some mail clients block remote images until the recipient allows them; the text links still work.
